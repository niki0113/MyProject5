## 0. 要約

- MPM は、段 C-1（変形勾配 F）、C-2（Neo-Hookean 弾性）、床のクーロン摩擦、D-1（Hencky ひずみの弾性）、D-2（Drucker-Prager の塑性）まで実装し、それぞれ期待値、数値解、実験則と照合した。
- 砂柱は、側面が崩れて斜面になり、塑性の流れが止まる。砂としての基本的な振る舞いが出ている。
- 次の段は安息角試験である。その前に、確認用に変えた設定を戻すかどうかを決める（6 節）。
- 大ゼミ（2026-10-28）の発表スライドと、発表スライドを作るためのスキルを作った。教授との発表練習で直してもらった版と点検結果の文書を受け取り、進捗の章を最新の結果に差し替える作業が残っている（8 節）。

## 2. 各モジュールの現在のコード

Claude Code のセッションで渡したコードを、段ごとの変更を反映した形でまとめた。
実機のコードと差がある場合は、実機を正とする。

### P2GScatter（Hencky ひずみの弾性応力つき）

```hlsl
// 粒子位置を格子座標へ（単位：マス）
float3 xg = (Position - GridOrigin) / CellSize;
int3 base = (int3)floor(xg - 0.5);
float3 f = xg - (float3)base;

// 二次 B スプラインの重み（各軸 3 点）
float3 w[3];
w[0] = 0.5 * (1.5 - f) * (1.5 - f);
w[1] = 0.75 - (f - 1.0) * (f - 1.0);
w[2] = 0.5 * (f - 0.5) * (f - 0.5);

float Orig;

// ラメ定数（ヤング率とポアソン比から）
float Mu     = YoungsModulus / (2.0 * (1.0 + PoissonRatio));
float Lambda = YoungsModulus * PoissonRatio / ((1.0 + PoissonRatio) * (1.0 - 2.0 * PoissonRatio));

// 左コーシー・グリーンテンソル b = F Fᵀ をヤコビ法で固有分解する：b = U diag(σ²) Uᵀ
float3x3 Fm = float3x3(F0, F1, F2);
float3x3 A  = mul(Fm, transpose(Fm));
float3x3 U  = float3x3(1,0,0, 0,1,0, 0,0,1);
for (int jsweep = 0; jsweep < 6; jsweep++)
{
    for (int jk = 0; jk < 3; jk++)
    {
        int p = (jk == 2) ? 1 : 0;   // (p, q) = (0,1), (0,2), (1,2)
        int q = (jk == 0) ? 1 : 2;
        float apq = A[p][q];
        if (abs(apq) > 1e-10)
        {
            float jth = (A[q][q] - A[p][p]) / (2.0 * apq);
            float jt  = (jth >= 0.0 ? 1.0 : -1.0) / (abs(jth) + sqrt(jth * jth + 1.0));
            float jc  = 1.0 / sqrt(jt * jt + 1.0);
            float js  = jt * jc;
            float3x3 R = float3x3(1,0,0, 0,1,0, 0,0,1);
            R[p][p] = jc; R[q][q] = jc; R[p][q] = js; R[q][p] = -js;
            A = mul(transpose(R), mul(A, R));   // p, q 成分を 0 にする回転
            U = mul(U, R);                      // 固有ベクトル（列）を積み上げる
        }
    }
}

// Hencky ひずみ ε_i = ln σ_i = ½ ln(σ_i²) と、主方向のキルヒホッフ応力
float3 eps = 0.5 * log(max(float3(A[0][0], A[1][1], A[2][2]), 1e-8));
float trEps = eps.x + eps.y + eps.z;
float3 kd = 2.0 * Mu * eps + Lambda * trEps;
float3x3 Tau = mul(U, mul(float3x3(kd.x,0,0, 0,kd.y,0, 0,0,kd.z), transpose(U)));

// MLS-MPM：Q = C − Δt (4/h²)(1/ρ₀) τ
float3x3 Q = float3x3(AffineC0, AffineC1, AffineC2)
           - SimDt * (4.0 / (CellSize * CellSize)) / Rho0 * Tau;

for (int i = 0; i < 3; i++)
for (int j = 0; j < 3; j++)
for (int k = 0; k < 3; k++)
{
    int3 node = base + int3(i, j, k);
    if (any(node < 0) || any((float3)node > NumCells - 1.0)) continue;

    float weight = w[i].x * w[j].y * w[k].z;
    float3 dpos = ((float3)node - xg) * CellSize;   // 粒子から格子点への差（cm）
    float3 mv = weight * (Velocity + mul(Q, dpos));
    Grid.InterlockedAddFloatGridValue(node.x, node.y, node.z, 0, weight, Orig);
    Grid.InterlockedAddFloatGridValue(node.x, node.y, node.z, 1, mv.x, Orig);
    Grid.InterlockedAddFloatGridValue(node.x, node.y, node.z, 2, mv.y, Orig);
    Grid.InterlockedAddFloatGridValue(node.x, node.y, node.z, 3, mv.z, Orig);
}
OutDummy = 1.0;
```

1/ρ₀ は、MLS-MPM の式の「初期体積 / 質量」にあたる。
キルヒホッフ応力 τ は初期体積あたりの量（τ = Jσ）なので、初期体積を使えばよい。
ヤコビ法の変数に `j` を付けているのは、下の足し込みのループの `i`、`j`、`k` と名前がぶつからないようにするためである（Niagara の HLSL では for の変数が外に漏れて再定義のエラーになることがある）。

### GridVelocityUpdate（減衰とクーロン摩擦つき）

```hlsl
// P2GGrid（このステージの繰り返し対象ではない）から重みと運動量を読む
float W, Px, Py, Pz;
Grid.GetFloatGridValue(IndexX, IndexY, IndexZ, 0, W);
Grid.GetFloatGridValue(IndexX, IndexY, IndexZ, 1, Px);
Grid.GetFloatGridValue(IndexX, IndexY, IndexZ, 2, Py);
Grid.GetFloatGridValue(IndexX, IndexY, IndexZ, 3, Pz);

// 速度 = 運動量 / 質量 + 重力 × Δt （粒子がないマスは 0）
float3 V = float3(0.0, 0.0, 0.0);
if (W > 1e-6)
{
    V = float3(Px, Py, Pz) / W + Gravity * DeltaTime;
    V *= 1.0 / (1.0 + Damping * DeltaTime);   // 確認用の減衰（Damping = 0 で無効）
}

// 床の境界条件：クーロン摩擦（床より下の格子点で、床に押し込む速度があるときだけ）
float NodeZ = GridOrigin.z + IndexZ * CellSize;
if (NodeZ <= FloorZ && V.z < 0.0)
{
    float vn = -V.z;               // 床に押し込む速さ
    float vtLen = length(V.xy);    // 床に沿った速さ
    V.z = 0.0;
    if (vtLen > 1e-6)
    {
        V.xy *= max(0.0, 1.0 - FloorFriction * vn / vtLen);
    }
}

// 側面の壁：格子の端2マス以内で外向きの速度を 0
if (IndexX < 2 && V.x < 0.0) V.x = 0.0;
if (IndexX > (int)NumCells.x - 3 && V.x > 0.0) V.x = 0.0;
if (IndexY < 2 && V.y < 0.0) V.y = 0.0;
if (IndexY > (int)NumCells.y - 3 && V.y > 0.0) V.y = 0.0;

// VelocityGrid の属性 0〜2 に速度を書く
VelGrid.SetFloatValueAtIndex(IndexX, IndexY, IndexZ, 0, V.x);
VelGrid.SetFloatValueAtIndex(IndexX, IndexY, IndexZ, 1, V.y);
VelGrid.SetFloatValueAtIndex(IndexX, IndexY, IndexZ, 2, V.z);
OutDummy = 1.0;
```

### G2PTransfer（F の更新と Drucker-Prager の戻し計算つき）

```hlsl
float3 xg = (Position - GridOrigin) / CellSize;
int3 base = (int3)floor(xg - 0.5);
float3 f = xg - (float3)base;
float3 w[3];
w[0] = 0.5 * (1.5 - f) * (1.5 - f);
w[1] = 0.75 - (f - 1.0) * (f - 1.0);
w[2] = 0.5 * (f - 0.5) * (f - 0.5);

float3 Vp = float3(0.0, 0.0, 0.0);
float3 B0 = float3(0.0, 0.0, 0.0);   // C の行を集める
float3 B1 = float3(0.0, 0.0, 0.0);
float3 B2 = float3(0.0, 0.0, 0.0);
for (int i = 0; i < 3; i++)
for (int j = 0; j < 3; j++)
for (int k = 0; k < 3; k++)
{
    int3 node = base + int3(i, j, k);
    if (any(node < 0) || any((float3)node > NumCells - 1.0)) continue;
    float weight = w[i].x * w[j].y * w[k].z;
    float vx, vy, vz;
    VelGrid.GetPreviousFloatValueAtIndex(node.x, node.y, node.z, 0, vx);
    VelGrid.GetPreviousFloatValueAtIndex(node.x, node.y, node.z, 1, vy);
    VelGrid.GetPreviousFloatValueAtIndex(node.x, node.y, node.z, 2, vz);
    float3 vi = float3(vx, vy, vz);
    float3 dpos = ((float3)node - xg) * CellSize;
    Vp += weight * vi;
    B0 += weight * vi.x * dpos;   // C_jk = (4/h²) Σ w v_j dpos_k
    B1 += weight * vi.y * dpos;
    B2 += weight * vi.z * dpos;
}

float Dinv = 4.0 / (CellSize * CellSize);
OutC0 = B0 * Dinv;
OutC1 = B1 * Dinv;
OutC2 = B2 * Dinv;

// 変形勾配の更新：F ← (I + Δt C) F（試しの弾性 F）
float3x3 Cm = float3x3(OutC0, OutC1, OutC2);
float3x3 Fm = mul(float3x3(1,0,0, 0,1,0, 0,0,1) + DeltaTime * Cm, float3x3(F0, F1, F2));

// ---- Drucker-Prager の降伏判定と戻し計算（Klár et al. 2016） ----
float Mu     = YoungsModulus / (2.0 * (1.0 + PoissonRatio));
float Lambda = YoungsModulus * PoissonRatio / ((1.0 + PoissonRatio) * (1.0 - 2.0 * PoissonRatio));
float sinPhi = sin(FrictionAngle * 3.14159265 / 180.0);
float alpha  = sqrt(2.0 / 3.0) * 2.0 * sinPhi / (3.0 - sinPhi);

// b = F Fᵀ をヤコビ法で固有分解する：b = U diag(σ²) Uᵀ（P2G と同じ計算）
float3x3 A = mul(Fm, transpose(Fm));
float3x3 U = float3x3(1,0,0, 0,1,0, 0,0,1);
for (int jsweep = 0; jsweep < 6; jsweep++)
{
    for (int jk = 0; jk < 3; jk++)
    {
        int p = (jk == 2) ? 1 : 0;
        int q = (jk == 0) ? 1 : 2;
        float apq = A[p][q];
        if (abs(apq) > 1e-10)
        {
            float jth = (A[q][q] - A[p][p]) / (2.0 * apq);
            float jt  = (jth >= 0.0 ? 1.0 : -1.0) / (abs(jth) + sqrt(jth * jth + 1.0));
            float jc  = 1.0 / sqrt(jt * jt + 1.0);
            float js  = jt * jc;
            float3x3 R = float3x3(1,0,0, 0,1,0, 0,0,1);
            R[p][p] = jc; R[q][q] = jc; R[p][q] = js; R[q][p] = -js;
            A = mul(transpose(R), mul(A, R));
            U = mul(U, R);
        }
    }
}

float3 eps    = 0.5 * log(max(float3(A[0][0], A[1][1], A[2][2]), 1e-8));   // Hencky ひずみ
float  trE    = eps.x + eps.y + eps.z;
float3 epsHat = eps - trE / 3.0;                                             // 偏差成分
float  nHat   = length(epsHat);
float3 epsNew = eps;
float  dgamma = 0.0;
if (trE >= 0.0)
{
    epsNew = float3(0.0, 0.0, 0.0);   // 引っ張り：応力ゼロに戻す（粘着力 0）
    dgamma = length(eps);
}
else
{
    dgamma = nHat + (3.0 * Lambda + 2.0 * Mu) / (2.0 * Mu) * trE * alpha;
    if (dgamma > 0.0)
    {
        epsNew = eps - dgamma * epsHat / max(nHat, 1e-10);   // 降伏面に戻す
    }
    else
    {
        dgamma = 0.0;   // 弾性のまま
    }
}

// F_new = U diag(σ_new / σ) Uᵀ F（もう一方の回転 V を求めずに済む形）
float3 ratio = exp(epsNew - eps);
Fm = mul(U, mul(float3x3(ratio.x,0,0, 0,ratio.y,0, 0,0,ratio.z), mul(transpose(U), Fm)));
OutPlastic = dgamma;

OutF0 = Fm[0];
OutF1 = Fm[1];
OutF2 = Fm[2];
OutJ  = determinant(Fm);   // 弾性部分の J（確認用）

OutVelocity = Vp;
OutPosition = Position + Vp * DeltaTime;

// 粒子が床を突き抜けない（非貫入）
if (OutPosition.z < FloorZ)
{
    OutPosition.z = FloorZ;
    OutVelocity.z = max(OutVelocity.z, 0.0);
}
```

## 3. 段ごとの理論と検証結果

比べた相手の種類を、点検の指摘（8 節）に合わせて次のように書き分ける。

- **期待値**：単純な条件で、定義や運動方程式、離散更新式から手計算で決まる値
- **数値解**：式は立つが手計算では解けず、1 次元の計算で求めた値
- **実験則**：実験から得られた経験的な関係

### C-1：変形勾配 F の更新

- 理論：F ← (I + ΔtC)F、J = det F。
- 自由落下中は全粒子の速度がそろい、二次 B スプラインの Σ w dpos = 0 から C = 0 なので F = I のまま（期待値）。
- 結果：フレーム 31 で全粒子 F = I、J = 1。Σw も内部 7.999、面 7.499、辺 5.499（期待値 8、7.5、5.5）。着地後の J は 0.83〜1.06 で、圧力モデルの静止状態（1 − J = g d / c²、床の直上で 0.89）に揺れが重なった範囲として理解できる。
- 着地後、F の非対角成分は ±1 前後まで溜まった（圧力だけではずれに抵抗しないため）。

### C-2：Neo-Hookean の弾性

- 理論：τ = μ(FFᵀ − I) + λ ln J · I、Q = C − Δt(4/h²)(1/ρ₀)τ。μ = 6.154、λ = 9.231、縦波の速さ 119.8 cm/s、cΔt/h ≈ 0.25。
- 着地前：τ = 0 なので F = I のまま（落下速度 −20.276 cm/s、期待値 −20.25）。
- 着地後：直方体を保つゼリー状の挙動。非対角成分は ±0.1 程度。
- 静止状態の比較（Damping = 10 で揺れを止めて比較。つり合いは減衰の強さに依存しない）。横に自由に広がる場合の 1 次元のつり合い（数値解）は次のとおり。

| 深さ | F0.X、F1.Y | F2.Z | J |
|---|---|---|---|
| 0.5 cm（最上段） | 1.002 | 0.992 | 0.997 |
| 4.5 cm | 1.020 | 0.935 | 0.973 |
| 9.5 cm（最下段） | 1.042 | 0.871 | 0.945 |

- 結果：下の段は 1% 以内で一致。上の段は横の伸びが 1.02〜1.03 と数値解（1.01）より大きい。数値解は各段が独立に横へ広がると仮定しているが、実際は一体のため横の伸びが高さ方向にならされる、と解釈した。
- 最上段（置いて始めた場合）：F2.Z 0.985〜0.994、J 0.99〜1.0。最下段から最上段までの高さ 8.53 cm（数値解 8.37〜8.52）。

### 床の境界の問題（未解決、4 節）

- 落とした場合、最下段の粒子は z ≈ −8.53 で止まり、F2.Z = 0.708、J = 0.775 と数値解より大きく縮んだ。
- 衝撃なしで置いた場合（Z オフセット −3.5）、z ≈ −8.83、F2.Z = 0.785、J = 0.85 に改善したが、数値解（0.87〜0.90）には届かない。

### 床のクーロン摩擦

- 理論：床より下の格子点で V.z < 0 のとき、法線の速さ vₙ を 0 にし、接線の速さを最大 μ_f vₙ 減らす。
- 確認：ブロックを X = 30 に縮め、重力を傾けて斜面を表した（θ = 20° は (−55.4, 0, −152.2)、35° は (−92.9, 0, −132.7)）。μ_f = 0.5、Damping = 10。減衰があると、滑る場合の定常の速さは g(sin θ − μ_f cos θ) / D になる（期待値）。

| 条件 | 期待値 | 結果 |
|---|---|---|
| 20°（tan θ = 0.36 < 0.5） | 止まる（摩擦なしなら −5.5 cm/s） | Velocity.X ±0.003 以内。F0.Z は最下段 −0.154（床が底を引き留めて上部が傾く） |
| 35°（tan θ = 0.70 > 0.5） | −2.66 cm/s で滑る | 平均およそ −2.7（上段 −2.9〜−3.05、最下段 −2.1〜−2.8） |

- 減衰なしでは 20° でも 7 cm ほど下った。弾性の揺れで床を押す力が下がるたびに少しずつ滑った、と推定している（未確認）。
- 途中、FloorFriction を結びつけ忘れて摩擦が 0 になり、20° で滑り続けた（7 節の落とし穴）。

### D-1：Hencky ひずみの弾性（Klár et al. 2016 と同じ弾性）

- 理論：b = FFᵀ = U diag(σ²) Uᵀ をヤコビ法で分解し、ε = ln σ、τ = U(2με + λ tr ε I)Uᵀ。
- 数値解（横に自由）：最上段 1.002、0.992、0.997。深さ 4.5 cm で 1.019、0.938、0.975。最下段 1.039、0.881、0.950。Neo-Hookean よりわずかに縮みが小さい。
- 結果：最下段 z −8.80〜−8.84、F2.Z 0.777〜0.805。最上段 z −0.24〜−0.29、F2.Z 0.992〜0.996。高さ 8.56 cm（C-2 は 8.53 cm）。差の向きと大きさが数値解と合い、NaN も出ていない。

### D-2：Drucker-Prager の塑性

- 理論：ε̂ = ε − tr ε/3、α = √(2/3) · 2 sin φ / (3 − sin φ)（φ = 35° で 0.354）、δγ = ‖ε̂‖ + (3λ + 2μ)/(2μ) · tr ε · α。δγ > 0 なら ε ← ε − δγ ε̂/‖ε̂‖、tr ε ≥ 0 なら ε ← 0。
- 最初の試験（60 × 30 × 10 のブロック）では崩れなかった。角の粒子の Plastic は 0.007〜0.013（毎秒 2 前後の塑性ひずみに相当）で降伏はしていたが、側面の壁がブロックの端から 1.5〜3.5 cm しか離れておらず、広がれなかった。
- 細長い砂柱（X = 20、Y = 30、Z = 10。y 方向は壁で平面ひずみ）、FloorFriction = 1.0、Damping = 0 で崩した。

| 量 | 結果 | 比較 |
|---|---|---|
| 裾の広がり | 両側に約 9.6 cm、(L∞ − L₀)/L₀ ≈ 0.96 | 実験則 1.2a = 1.2（a = H/L₀ = 1、Lube et al. 2005 など）より 2 割小さい |
| 中央の上面 | z ≈ −1.4〜−1.8（弾性の −0.25 から約 1.2 cm 低下） | 中央の高さが保たれるのは a がおよそ 0.7 未満（Lajeunesse et al. 2005）。a = 1 はその境目を超える |
| 斜面の平均の傾き | 約 24° | φ = 35° より緩い |
| Plastic（表示 8 秒台） | ほぼすべて 0 | 塑性の流れは止まった。残る Velocity.Z ≈ −0.45 cm/s は振幅 0.02 cm 程度の弾性の揺れと推定 |

- 裾の先端の粒子は F0.X ≈ −0.4、F0.Z ≈ −0.93、J ≈ 0.98 で、体積を保ったまま 100° 以上回転していた（崩れた側面が転がるように前に出た跡）。元の底の角（x ≈ ±10〜11）には大きなずれ（F0.Z ≈ ±0.79）が残り、底の角からのすべり面と合う。
- 実験則との 2 割の差は、格子の粗さ（高さ方向 5 マス）、土台の摩擦、実験則のばらつきが候補。

## 4. 未解決の点と注意

1. **床に接する1マスの過大な縮み**：床の条件を格子点に掛けているため、粒子は床の格子点（z = −10）から 1.2〜1.5 cm 上で止まり、z −10〜−8 のマスに入る粒子が少ない。そのため 1 粒子あたりの応力が大きくなり、余分に縮んでいると考えている（推定）。格子を細かくすると薄くなるかを、解像度の収束確認で確かめる。床の高さを測る試験では、実効の床面が約 −8.5〜−8.8 にあることに注意する。
2. **側面の壁が近い**：壁は格子の端から2マス（x = −34 以下と 32 以上、y = −18 以下と 16 以上の格子点）。元の 60 × 30 × 10 のブロックは始めから壁に押さえられる。崩壊や堆積の試験では、粒子の範囲を小さくするか、格子を広げる。
3. **C_zz = −0.675 の意味**：床に静止した粒子（z = −10 cm）の周りの格子点 z = −12、−10、−8 のうち、床の条件で下の2点の速度は 0、z = −8 だけが重力で −2.7 cm/s を持つ（Δt = 1/60 s のとき）。C_zz = (4/h²) × 0.125 × (−2.7) × 2 = −0.675 /s。物理的な静止状態の速度勾配（0）ではなく、床の境界が離散的に作る見かけの値である。圧力を入れる前に床の上で体積が縮み続けた（J が 0.055 まで低下）のも、この見かけの圧縮による。
4. **減衰なしの斜面で少しずつ滑る**：弾性の揺れによる推定で、未確認。塑性を入れた後は揺れが塑性で吸収されるので、小さくなる見込み。
5. **計算時間は未測定**：Δt = 1/240 s はシミュレーションの時間刻みで、実行速度ではない。Niagara のプレビューでコンソールに `stat GPU` と打てば 1 フレームの時間が出る。

## 5. 硬さと安定条件（質疑用の整理）

- 硬さ「1600 Pa」はヤング率 E（E = 16 kg/(cm·s²)）。ポアソン比 0.3。
- 係数 0.25 は cΔt/h（1 ステップで波が進む距離が格子間隔の何割か）。1 より十分小さくなるよう、余裕を見て選んだ値で、理論的な上限ではない。
- 実物の剛性（MPa 級。出典と条件は要確認）に近づけるには、サブステップで Δt を小さくする必要があり、計算負荷が増える。実時間性能との兼ね合いが評価項目になる。
